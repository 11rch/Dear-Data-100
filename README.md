This project consists of data that I collected on my usage of digital devices for longer than an hour.
I have collected them in notes form by putting the data into a table on samsung notes and have also visualized them on a sketch using processing code.
The main questions I am trying to answer by collecting this data is how much time I spend on each device (minimum 1 hour at a time), phone, laptop, console, etc.
I am collected when I tend to use my devices, for what reason (entertainment, socials, studies, etc), how long at a single time, specific apps, etc.
